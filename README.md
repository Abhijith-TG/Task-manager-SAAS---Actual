# Task Manager SaaS

A full-stack Task Manager SaaS application built with the MERN stack.  
This project is being developed as a portfolio-level SaaS product with authentication, task management, teams, roles, and dashboards.

## 🚀 Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt
